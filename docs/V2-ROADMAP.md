# V2 目标（待做清单）

> 这份文件是「以后要做什么」的备忘录，**不是承诺**。每条都写了：为什么做、大概多大、什么情况下才轮到它。

## 先说清楚这个仓库是什么

**它是整合出来的，不是从零写的。**

- 底座是上游 **SurfCore v0.8.1**（`Mieksido/surfcore`，MIT）；
- 上面叠的是我这两个月踩坑踩出来的改造（人格分层、记忆隔离、唤醒闸门、成本账单、面板……）；
- 还有一部分是**别人提的**、我判断值得就吸收进来的（记忆换存储、插件化、检索模型），这些记在下面，标了来源。

所以看这个仓库的正确姿势是：**一份「怎么把别人的 QQ 机器人改到能长期用」的参考实现**，不是开箱即用的产品。

## V2 待做（按优先级排）

### 1. 记忆表格化：JSON → SQLite（含 FTS5）

- **来源**：朋友建议（「记忆要另作存储，表格、索引、检索模型」）。
- **为什么**：现在是一个 JSON 全量读进内存、写就重写整文件。条数到 3000~5000，或者开多个会话并发写，就会开始难受；换表之后单条更新、按会话/时间查询、全文检索都是现成的。
- **成本**：1~2 天（含面板 20 多个查询改造 + 迁移脚本 + 回滚方案）。
- **触发条件**：记忆条数 > 3000，或者出现并发写问题。
- **注意**：Node 22 自带 `node:sqlite`，不引入新依赖；迁移必须先备份再跑一次 dry-run。

### 2. 向量检索（embedding，混合召回）

- **来源**：同上（「检索模型」）。
- **为什么**：现在纯词面匹配，换个说法就想不起来。混合检索（词面命中不够再走向量）能明显改善「你以前跟我说过…」这类回忆。
- **成本**：2~3 天（向量化 590 条 + 增量 + 查询 + 存储约 1.2MB；embedding 来源要选：远程 API 还是本地 ONNX）。
- **触发条件**：索引做完后实测召回不够用（可以先攒一批「她说想不起来」的真实 case 再决定）。
- **风险**：远程 API 有成本和延迟；本地模型有体积和冷启动。

### 3. 插件目录化 / 创造模式

- **来源**：我的判断 + 朋友建议（「功能做成插件」）。
- **为什么**：现在 `src/ext` 已经是插件的骨架（6 个钩子 + 工具注册表），但还是「编译进仓库」。做成扫描 `plugins/` 目录动态 `import()` 之后，加功能不用改桥接，别人也能只装一个功能包。
- **成本**：2~3 天 MVP（目录扫描 + 元数据校验 + 面板「插件」页 + 启用开关 + 权限收敛）。
- **三个必须先解决的**：①插件能读 config、能发消息，等于任意代码执行，只能给 ctx 不给 fs/net；②钩子签名一变旧插件全废，要定 semver；③每个插件都吃提示词预算，得有统一预算和开关。
- **触发条件**：V1 分享出去、收到「我只想要某个功能」的需求之后。

### 4. 一键安装 + 配置向导

- **来源**：分享的现实障碍。
- **为什么**：现在要装 NapCat/OneBot + DSH + Node 22 + 手填 `config.json` + 写人格卡。没有 `install.sh` 和配置向导，别人第一步就卡住。
- **成本**：0.5~1 天（`install.sh` + `config.example.json` 填一遍 + 启动自检）。
- **触发条件**：真有人要装的时候（否则容易做成了一半没人用的脚本）。

### 5. Windows / SnowLuma 桌面版适配

- **来源**：大多数 SnowLuma 用户是 Windows。
- **为什么**：现在 `scripts/`、systemd、`runuser`、`ps` 都是 Linux 写法；面板也假设 Linux。
- **成本**：2 天起（要跑通 Node 启动、路径、进程管理、日志轮转），且我没 Windows 环境做回归——**这条风险最高，收益最不确定**。
- **触发条件**：除非有人愿意当小白鼠，否则只写「Linux only，Windows 未验证」。

### 6. 通道抽象再往前走一步

- **为什么**：`channel` 段名已经支持了（兼容旧 `snowluma`），但代码里仍然是 OneBot v11 语义。
- **成本**：1~2 天。
- **触发条件**：接入第三种实现（比如 Lagrange / LLOneBot）时再做。

### 7. 面板细节

- 通道健康的历史曲线（现在只有最近一次探测）
- 插件页（跟着第 3 条一起）
- 记忆条目直接编辑（现在只能钉住/淡忘/只展示）
- 花费页：按模型拆分、按月预算

### 8. 还挂在墙上的小事

- B 站动态：现在 `dynamics.enabled=false`（日志里 `feed/space code=412` 是昨天的），要不要重开另说
- QQ 空间「看说说」依赖 `get_cookies`，SnowLuma 上没有等效实现，只能降级
- 语音：只做了「听」，没做「说」
- 群内多角色：现在是「一个角色多会话」，没有真正做到「不同群不同人设」
