# 架构决策记录（DECISIONS）

> 记录「为什么这么选」以及「什么信号说明该重新考虑」。每条包含：背景 / 选择 / 代价 / 复查点。
> 维护规则：每新增 10 个补丁标记，必须在这里写一条评估。

## D-001 人格分四层（核心 / 语气 / 场景 / 日常）

- 背景：0.8.1 上游把人格卡按场合分层注入，群聊只装语气层，省 token。
- 选择：沿用上游分层；额外补 `persona.daily.md` 与 `persona.scenes/*`（群里加 300 字核心，解决“没底气”）。
- 代价：两处文件要同步维护；群聊省下的 token 被 300 字核心抵消一部分。
- 复查点：若群里仍频繁“顺着别人评价走”，考虑群聊改注入全量核心（需把 `role.maxInjectChars` 提到 7500）。

## D-002 补丁 → 扩展钩子（M2）

- 背景：`bridge.js` 一周内累积 96 处 `_PATCH`，加功能要在多处登记。
- 选择：抽出 6 个钩子（route/promptBlocks/stateKey/onGroupMessage/onPrivateMessage/wakeGate/afterSend）+ `src/ext/` 模块化，`_PATCH` 降到 74。
- 代价：迁移期改动面大、需要逐模块验证；旧补丁与新钩子并存一段时间。
- 复查点：再加 10 个补丁仍超过 3 处登记 → 继续把 `bridge.js` 剩余块迁出。

## D-003 一级注意力判定（本地打分，零成本）

- 背景：群消息一条条唤醒，大量是不值得接的话，花钱且显得话痨。
- 选择：本地打分（叫名字 +4、问句 +2、求助 +2、长度≥8 +1；@别人 −3、太短 −2、只有图 −2、重复 −3），低于阈值不唤醒；不调用模型。
- 代价：阈值偏严会漏掉该接的话；需要日志观察误杀。
- 复查点：连续一周出现“该接没接”，把 `minScore` 从 2 降到 1。

## D-004 记忆注入用「短句 + 框架」，不用原话

- 背景：学说法样本是长句，直接注入会占预算、且她照搬像演戏。
- 选择：样本加 `short`（可直接说的一句）与 `why`（框架），注入优先用 `short`。
- 代价：长样本要人工/脚本拆短句；拆得不好会失去原味。
- 复查点：若注入后她的句式没有变化，说明短句抽取太保守，改人工挑选。

## D-005 免费额度只用于「可重跑、不敏感」的支线

- 背景：学生预算有限，WorkBuddy 白嫖 / MiniMax 赠金都不可持续。
- 选择：主链路只用官方 deepseek-flash；免费额度只给开发杂活与字幕摘要等可重跑任务；不自动回落（回落逻辑出错会让她静默不回）。
- 代价：省不了主链路的钱，只能省辅助任务。
- 复查点：若官方涨价或额度受限，再评估模型路由（backlog 已记录）。
