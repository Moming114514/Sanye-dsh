## 已核实

### four-point-hooks（社区 PR #1，作者 baizhi06）
- 我实际看过的东西：`src/ext/four-point-hooks.js`（231 行）+ 接入文档（89 行）。
- 亮点：七个入口收成四处（incoming/gate/context/outbound）；**每个扩展独立 try/catch**；`stateKey` 只算声明 cache 的扩展。
- 可复用的只有一块：**每扩展隔离**——我们踩过 afterSend 抛错中断整条发送的坑。
- 不用的原因：我们 20+ 模块按老钩子注册，换四孔要重写 `src/ext/index.js`，改动面太大。
- 结论：留作 V2「入口收拢」的参考，不合并 PR。
