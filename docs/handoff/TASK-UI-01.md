## 一、面板布局（主任务）

### 1.1 侧栏重排（分组 + 分隔线）

现在 14 项平铺，改成 5 组：

```
状态：总览、入口
她的言行：安全、白名单、学说话、人群档案、她说的话
记忆与心情：记忆与情绪、她的看法、记忆星海、记忆体检
花费：花费
系统：设置、命令大全、排障
```

要求：组名小字号灰字，不可点击；分隔线；手机上保持底部横向导航（现在已实现，别破坏）。

### 1.2 每页顶部加「本页能调什么」

每页第一张卡之前插一行灰色说明，格式统一：

```
本页能调：省钱模式、群频率、敏感词表、按群规则 —— 都在这一页，不用去别处
```

内容按页面写死即可（不要求动态）。目的是"不用跑来找"。

### 1.3 开关与设置项标注「生效方式」

功能开关页每行已有 `effect` 字段（立即 / 重启桥接）。要求：
- 统一在**每一行右侧**显示小标签：`立即` 绿 / `需重启` 橙；
- 在页面顶部写清：「改完标『需重启』的，回设置页点一次『立即重启让它们生效』」。

### 1.4 页内快速跳转（可选，时间够再做）
