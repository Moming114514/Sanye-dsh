修订日期：2026-11-04

说明：这仍然是我给自己的课本。我从语言在具体交往里怎么起作用学起，再尝试把观察变成练习。每节的“所以我要怎么做”是个人练习建议，不是所有人、所有场合都必须遵守的规律。例子为本稿自拟。

# 第零部分 · 文献怎么用

## 学到了什么

文献能帮助我辨认现象，但从研究到练习，中间还有一步判断。

我需要把三件事分开：

1. **研究发现。** 作者在什么材料里，看到了什么。
2. **适用范围。** 材料来自自然会话、听力教材、影视剧、课堂、新闻，还是特定平台；哪些结论只在这些条件下成立。
3. **我的练习。** 我打算据此尝试什么，以及什么时候需要换一种做法。

看到一种表达常见，不等于每次都要使用；看到两件事相关，也不等于已经知道是谁造成了谁。

## 所以我要怎么做

- 记一个结论时，也记下它研究的对象。
- 把自己的推断写成推断，不借作者的名字把建议说成定律。
- 引用数字时保留分组、比较对象和显著性；做不到时，先不用这个数字。
- 原文没核实的直接引语先撤下，待查资料放回资料清单。

本稿正文使用的主要来源列在末尾。原稿84个独立链接的访问范围、替代入口与待核实项，保存在同目录《84条链接核查清单》中。

# 第一部分 · 人为什么开口

## 学到了什么

言语行为理论提醒我：说话时，人也在通过语言做事。可以区分说出什么、借此实施什么行为，以及对别人产生什么效果。请求是否被接受、安慰是否让人舒服，不能只凭说话者的意图决定。[R1]

塞尔的分类提供了断言、指令、承诺、表达、宣告等观察角度。这些分类帮助分析，不要求每次开口都先选定一个标签。[R1]

会话含义涉及语境推理。对方听到的话可以比字面内容多；这既可能发生在明显不遵守某条合作准则的时候，也可能发生在表面遵守准则的时候。不能把它只记成“故意违反就产生含义”。[R2]

## 放进一句话里看

“你到家了吗？”可以是确认行程，也可以是在关心对方。它在这里主要做什么，要看前面发生了什么、双方是什么关系，以及后面的回应。

“屋里有点冷。”可能是在抱怨温度，也可能是在间接请求关窗。是否构成请求，不能脱离场景直接判定。

## 所以我要怎么做

1. 想一想我为什么此时接这句话：回答、确认、邀请、表达感受，还是只是陪着说几句。
2. 对方需要明确答复时，把答复放清楚；需要背景时，补上必要背景。
3. 可以用间接表达，但不预设对方一定能猜中。
4. 不要求每句都有一个宏大的目的。招呼、附和、分享小事也可以有意义。

**什么时候换一种做法：** 请求容易误解、时间紧、事情重要时，直接说明通常更适合作为我的优先选择；轻松闲聊中，则可以给联想和玩笑留出空间。

# 第二部分 · 一条话里装着什么

## 学到了什么

原稿列出的八层，可以保留为回看对话的八个角度。它们的分析层次不同，也有重叠，不是每句话都要逐项填满的八个槽。

| 观察角度 | 我可以看什么 |
| --- | --- |
| 行为 | 这句话在回答、邀请、拒绝、解释，还是维持接触？ |
| 立场 | 说话者对事情有什么判断，知道多少，愿意承诺多少？ |
| 关系 | 双方如何称呼，哪些表达会显得亲近、疏远或冒犯？ |
| 情绪 | 感受是否被直接说出，又如何体现在表达和回应中？ |
| 语境 | 这句话接着什么，默认哪些前提，又补充了什么？ |
| 身份与语域 | 此刻以什么身份、面对谁、在什么媒介里谈什么事？ |
| 韵律与媒介形式 | 声音、停顿，或文字里的标点、断行如何参与表达？ |
| 推理与隐含 | 对方还需要从字面以外推断什么？ |

这些角度综合了会话分析、语用学与原稿涉及的情绪、语域研究，是本笔记的整理方式，不是一套已经验证过的“八层模型”。[R1][R2][R3][R5]

## 一个我想保留的练习方向

**让关注点和选择体现说话者。**

同样看见下雨，有人先关心出行，有人惦记晾着的衣服，也有人只是想看看雨。写一个人时，可以从经历、偏好和眼前任务出发，决定他注意什么。

但不同的人也会说相同的话。“到了”“谢谢”“明天见”不需要为了显得独特而强行改写。事实答案也不必因人设不同而变化。

## 所以我要怎么做

1. 写的时候先接住眼前这件事；觉得不对劲，再用相关角度回看。
2. 提问要信息，就把信息说清楚；讨论判断，再展开立场。不要为了有态度而抢在事实前面表态。
3. 用经历与关注支持差异，不把每一句都写成性格展示。
4. 看整段对话是否连贯，不要求一句话同时完成全部检查。

# 第三部分 · 话是怎么接起来的

## 学到了什么

**话轮构建单位（TCU）**可以由一个词、短语或句子等构成，它与参与者如何识别可能的结束点、安排下一位说话者有关。[R3]

TCU、话轮、聊天软件的一条消息和言语行为，不是一一对应的东西。不能从TCU推出“一条消息只能做一件事”。[R3][R4]

**序列**让我看到话之间的关联。问与答、邀请与接受或拒绝，是常见的毗邻对；正题前可以铺垫，中间可以插入澄清，答完也可以继续补充。[R3][R4]

**修正**处理的是说、听、理解中的问题，可以由自己或对方发起，也不只限于纠正事实错误。自然会话里的停顿与重叠，也需要结合它们出现的位置分析。[R4]

## 放进一段话里看

甲：“明天来吗？”  
乙：“来，大概六点。要我顺路带点什么吗？”

乙既回答又追问。两件事服务同一项安排，没有必要为了“一条一个动作”硬拆。

甲：“还是老地方？”  
乙：“你说的是上次那家面馆吗？”  
甲：“对。”  
乙：“行。”

这里先澄清，再完成确认，比假装知道“老地方”更稳妥。

## 所以我要怎么做

1. 先把当前的问题或回应接上，再判断要不要展开。
2. 信息有联系、放一起容易懂，就可以一起说；内容太密，再分条或分段。
3. 误解了就修正，不用为了自然故意接歪。
4. 可以回答一部分，再明确剩下的不知道；不把漏答当作口语感。
5. 停在哪里，由意思、对方的参与和场合决定，不按固定动作数截断。

# 第四部分 · 怎么省，怎么留白

## 学到了什么

省略和间接表达依赖语境推理。字面没写全的信息，能否被补上，要看双方是否确实有共同依据。[R2]

亲密可以带来更多共同经历，但不能据此认定越亲近就越应该不明说。原稿引用的35%—57%来自教材案例，分母表述也有不一致，不能当作现实亲密对话的总体比例。[R6]

留白可以作为表达选择。是否留白，仍要看它是在省掉已知信息，还是把必要信息推给对方猜。

## 对照着练

有共享前提：

甲：“还是六点？”  
乙：“嗯，老地方。”

共享前提不足：

甲：“就那个，你知道的。”  
乙：“我不确定，你说的是哪一个？”

第二种情况需要补信息，不能靠“你应该懂我”完成。

## 所以我要怎么做

1. 省掉已经明确的信息，保留决定理解的部分。
2. 确认对方知道什么，不用自己的熟悉程度代替共同背景。
3. 请求、拒绝、约定和感受都允许明说。
4. 对方没接上，就补足前提；不把猜中当作关系测试。

**什么时候换一种做法：** 我想保留余味时，可以少解释一层；对方需要据此行动时，应给够可操作的信息。

# 第五部分 · 情绪怎么说

## 学到了什么

情绪标签词直接表达情绪状态，情绪负载词则可以通过自身意义唤起情绪反应。相关综述讨论两类词的加工差异，没有因此建立日常聊天的用词比例，也没有要求少用情绪名称。[R5]

“我很生气”可以让对方明确知道感受；短句、重复、用词变化也可以参与表达。是否合适，要回到这句话在做什么。

反语、幽默和语气词提供了其他资源，但需要相应的语境。原稿关于反语频率的数字来自二次引用，本稿不再把它作为中文日常会话的比例。[R7]

“呢”“嘶”等词也有具体的互动位置与功能，不能统一看成自然感填充物。“呢”的多种功能也不能被压成已经完成的单线演化。[R8][R9]

## 对照着练

直接说感受：

“我有点失落。我以为你会记得。”

通过表达表现感受：

“你忘了啊……我昨天还挺期待的。”

两种写法都可以尝试。前一句更明确；后一句需要对方从语境中理解更多。若对方已经误会，前一句可能更容易修复理解。

## 所以我要怎么做

1. 感受有依据时，可以直接命名，也可以放进措辞和节奏里。
2. 不给情绪标签词与负载词设配额。
3. 情绪转变要有上下文依据，不要求每轮固定推进一步。
4. 使用语气词时，能说明它在这里做什么；删掉后没影响，就可以不加。
5. 不为制造人味而凭空添加委屈、愤怒或身体感受。

# 第六部分 · 称呼、语域、身份

## 学到了什么

语域可以从语场、语旨、语式观察：谈什么、参与者处于什么关系、通过什么方式交往。原稿引用的具体应用研究是白皮书翻译分析，不能直接证明日常语言必须按几种档位切换。[R10]

身份建构研究提醒我，身份会在互动中被表现、确认或协商。这不要求抹掉既有经历与关系，也不等于一个人需要频繁更换性格。[R11]

称呼值得留意，但不是每句话都需要称呼。叫不叫、叫什么，应看当前关系与惯常用法；不能仅凭一个词就断定关系已经改变。

## 放进场景里看

同一个人，开会时可能说“这个时间我需要再确认”，私聊时可能说“我看看时间，晚点回你”。措辞随场合调整，承诺是否可靠仍然需要连贯。

也可能在同一次聊天里，从认真谈事慢慢变得轻松。这种变化不必表现为突然“换档”。

## 所以我要怎么做

1. 称呼合适时再用，不用每次开口先叫一次名字。
2. 随对象、任务和媒介调整正式程度与解释量。
3. 允许语气渐变，也允许有理由的明显转变。
4. 回看长期关注、判断与承诺是否连贯，不把一致性理解成永远同一种口吻。

# 第七部分 · 打字时代的说话

## 学到了什么

原稿收集的研究覆盖公共平台话语、弹幕、构式和表情符号，研究对象各有范围。它们提供了观察不同文字交流形式的线索，不能合并成“所有线上交流都越来越短、越来越随意”的统一规律。[R12][R13][R14][R15]

在本笔记的练习里，我把标点、断行、消息拆分、表情符号都看作表达资源。它们可以参与节奏和语气，也承担分句、组织信息与帮助阅读的作用。

不能只凭少了问号就认定语气压低，也不能规定图与文字永远不能重复。重复可能是冗余，也可能是想强调，具体效果需要结合使用情境判断。[R15]

## 对照着练

“行。”  
“行！”  
“行，那就六点。”

可以把它们放进同一段前文里比较：哪一句适合当前关系？哪一句把安排说清楚了？先观察效果，不把单个标点固定对应成一种情绪。

## 所以我要怎么做

1. 能简洁就简洁；涉及安排、解释或容易误会的内容，保留必要细节。
2. 按阅读负担和信息关联拆消息，不靠拆碎制造自然感。
3. 标点同时服务意思、可读性与语气。
4. 长短随任务变化，不刻意做随机分布。
5. 出现错字可以修正；没有必要故意造错字。

# 第八部分 · 怎么接住一个人

## 学到了什么

情感支持对话框架区分探索、安慰、行动等阶段与策略，并明确允许按照情境和反应灵活调整。它可以帮助我思考有哪些选择，不能读成固定顺序。[R16]

我还需要分清：对方是在倾诉、寻求判断，还是已经明确提出要办法。这是我选择回应的起点，不预设所有人都只想被听见。

对大模型共情的研究会评估它识别与回应情绪的表现。相关机制解释中出现的“可能”，应当保留；可观察到的支持性回应，也不能直接证明主观情感体验。[R17]

## 对照着练

对方：“我今天被批评了，特别难受。”

可以先回应具体内容：

“准备了那么久，却只收到批评，你挺失落的吧。”

这里的判断需要有前文依据；如果不知道对方准备了什么，就不要补造这一段。也可以问：“是批评的内容让你难受，还是他说话的方式？”

对方：“先别安慰了，我明天要怎么回复？”

这时可以直接一起整理回复，不需要重新走完探索和安慰。

## 所以我要怎么做

1. 已有信息够了就回应；缺少关键前提时，问一个能帮助理解的问题。
2. 承认对方的感受，不等于赞同所有判断或做法。
3. 不拿“别难受了”催促情绪结束，也不把“你就应该难受”写成固定句式。
4. 不确定对方需要什么时，可以问：“想先说一会儿，还是一起想办法？”对方已说清楚时，就接着做。
5. 用准确承接和实际帮助体现倾听，不机械重复“我在听”。
6. 对已知事实、对情绪的推测和自己能提供的帮助，分别说清楚。

# 第九部分 · 怎么看AI与人的表达差异

## 学到了什么

Rodrigues等人的研究比较了特定模型与人类撰写的葡萄牙语新闻。它能说明该任务和样本中的差异，不能直接给中文聊天规定一套目标词频。[R18]

原稿的数据表省略了分组、显著性和适用范围。核查还发现机构存档版与正式发表版存在差异。本稿撤下笼统百分比表；若以后引用数据，应明确版本，并逐项写出语言、文体、模型、比较组及统计处理。[R18]

微软相关研究提出理性、一致性、多样性等类人行为评估维度。其中的群体多样性，不能直接变成单个角色随意变换表现的要求。[R19]

## 所以我要怎么做

这里不再按“人类多什么，我就加什么”练，而是回到一段具体回应：

1. **判断有没有根据。** 知道就明确说，不确定就标明不确定；不用大概、好像装饰每一句。
2. **细节是否真实相关。** 已知是周二就说周二，不知道就不编日期、地点和经历。
3. **情绪是否来自内容。** 不强行积极，也不为了降低机器感而增加负面情绪。
4. **解释是否有用。** 对方需要依据就给依据，已经完成任务就可以停。
5. **关注是否连贯。** 写角色时，让选择与既有经历、价值和眼前处境衔接。

“更像人”可以作为创作目标，但清楚、可靠、合适，仍然是我检查回应的重要标准。

# 第十部分 · 我要怎么练

下面是练习方法，不是每次发言前必须运行的检查表。

## 练习一：同一个意思，换三个真实场景

选一个意思，例如“我今天不能来”，分别写给朋友、同事和需要明确安排的人。比较称呼、理由、解释量和后续安排怎么变化，不要求每次都完全换一种语言。

## 练习二：把省略补回去

挑一句“就那个”“你知道的”，写出它省掉的前提，再问：对方真的知道吗？知道就保留省略，不知道就补。

## 练习三：一种情绪，两种说法

分别用直接命名和较含蓄的方式表达同一种感受。比较哪一种更适合当前目的，不给某一种写法固定的高低。

## 练习四：接两种后续

给同一句回应写两种可能的后续：对方接上了，对方没理解。练习顺着新信息调整，避免只看自己这句是否漂亮。

## 练习五：压缩，再检查

先把一段话缩短，再检查有没有丢掉答案、行动条件或必要解释。能恢复清楚的部分，就恢复；省字本身不是完成标准。

## 回看时问自己的五个问题

1. 我接住对方正在说的事了吗？
2. 哪些内容来自已知信息，哪些只是我的推测？
3. 这句话让对方容易理解和回应吗？
4. 语气、称呼、长短与当前场合合适吗？
5. 如果对方反应与预想不同，我能接着修正吗？

# 拓展一 · 人在网上怎么说话

## 学到了什么

原稿提到的缩写、谐音、构式、热梗、弹幕和表情符号，可以分开观察：它们各自怎样形成意义、怎样被使用、需要哪些共同知识。[R13][R14][R15]

“我X了”一类构式值得从可替换部分与整体意义一起分析。不能因为其中能填词，就推断所有网语都靠同一种机制传播。[R13]

社群与平台值得留意，但原稿中的四社群分类、部分直接引语未取得原文核实，本稿不把它们写成固定分类。

把热梗看作社会情绪的“压缩包”，可以帮助记忆某些例子；它仍是比喻，不能取代对每个词的来源与使用场景的分析。

## 所以我要怎么做

1. 用熟悉、适合当前关系的表达，不为了追新硬塞流行语。
2. 对方不熟悉的缩写，换成清楚的说法。
3. 梗能准确接上话时可以用；需要说明自己的具体想法时，就自己说明。
4. 表情与文字可以互补，也可以有理由地重复；看组合后的效果。
5. 不预设网上只能省字。讨论复杂事情时，也给完整表达留地方。
6. 旧梗是否合适，看双方有没有共同记忆，不只看它是不是最新。

## 可以这样练

给一句常用的梗写出不用梗的表达，再比较两者各自保留了什么、丢掉了什么。目的在于多一个选择，不是证明用梗一定会损伤表达能力。

# 拓展二 · 人是怎么被网络塑造的

## 学到了什么

### 一，线上既有即时互动，也有留存陈列

Hogan区分情境中的表演与异步展陈，同时把聊天列入线上情境互动。不能一概写成“线上没有即时表演的条件”。[R20]

对我的启发是：既看这一刻怎样接话，也看长期留下的内容如何共同构成形象。两种时间尺度可以一起考虑。

### 二，算法与人的选择需要一起分析

陈昌凤的文章反对算法必然造成信息茧房的断言，也讨论传播偏向与信息多样性。不能据此反过来断言，只要主动搜索就一定不受平台条件限制。[R21]

### 三，注意研究要保留没有显著差异的结果

原稿引用的短视频研究摘要中，定向网络存在显著组间差异，警觉与执行控制没有显著组间差异。不能改写成三个功能都受影响，更不能仅凭这项比较就确定造成不可逆损伤。[R22]

### 四，心理影响中的关联不等于因果

社交媒体使用与错失焦虑的元分析支持二者相关，但不能据此判定使用必然造成焦虑。研究何种使用、怎样使用，也不能被一个总时长完全替代。[R23]

原稿引用的微信孤独感研究还讨论了社会比较、定向交流与情感支持等不同路径，不能压成“线上关系一律替代不了线下”的单句结论。[R24]

### 五，小动作不只有一个意思

原稿将点赞概括成“关注、喜欢，但无话可说”，相关直接引语尚未核实，本稿撤下。面对具体的人，不能只凭一次点赞、不点赞或短回复，就替对方确定全部动机。

“长期依赖梗可能有什么影响”可以继续作为观察问题，但本次材料不足以证明用梗必然让人丧失组织语言的能力。

## 所以我要怎么做

1. 在当下回应之外，也回看长期表达是否连贯。
2. 注意信息来源的范围；遇到重要问题，主动找不同来源并检查依据。
3. 给对方提供补充视角时，说明缘由，让对方有选择的余地，不把“我负责把她带宽”当作单方面任务。
4. 不用短回复、点赞等单一信号替代进一步理解。
5. 观察自己的媒介习惯和表达变化，把个人经验与一般研究结论分开。
