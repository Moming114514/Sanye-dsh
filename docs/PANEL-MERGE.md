# 面板整合方案（我建议的最终形态）

> 目标：**任何一个设置，最多点 2 次能改到；任何一个状态，1 屏能看明白。**
> 原则：合并同类项、删掉重复入口、统一"生效"语义；不推倒重写，页面代码可逐页替换。

---

## 一、最终结构（3 页 · 11 个视图）

```
┌ 现在 ──────────────────────────────┐
│ 概览   今天怎么样（1 屏答完）        │
│ 她的话  最近说了什么（含打标）        │
│ 钱     花了多少、花在哪              │
│ 健康   服务/端口/自检/媒体/错误       │
└───────────────────────────────────┘
┌ 她 ───────────────────────────────┐
│ 性格   人格四层摘要（只读）+ 边界    │
│ 说话   学说法样本 · 她的看法 · 印象  │
│ 记忆   记忆卡 · 体检 · 星海          │
│ 群规则  每个群一行（核心）           │
│ 人     白名单 · 人群档案 · 静音      │
└───────────────────────────────────┘
┌ 系统 ─────────────────────────────┐
│ 设置   26 个开关（分 5 组）          │
│ 命令   /帮助 命令大全               │
│ 维护   重启 · 待生效 · 备份 · 排障   │
└───────────────────────────────────┘
```

一级导航 **3 个**（现在 6 组 20 页），二级 11 个视图（现在是"20 页 + 页内 Tab"混着）。

## 二、最大的一处合并：「群规则」

现在"她在这个群说不说"被 6 处控制，分散在 3 个页面。合并成**一个表**：

| 群 | 在群里？ | 怎么回 | 发言量 | 只回谁 | 抽样 | 今天 |
|---|---|---|---|---|---|---|
| 烤研学习交流群 680787260 | ✅ | 正常聊 | 2 分钟 / 120 次 | — | — | 3/120 |
| 荔枝立志记 1043145514 | ✅ | 只回@ | 15 分钟 / 12 次 | — | — | 0/12 |
| 小咪的窝儿② 389834620 | ✅ | 正常聊 | 1 分钟 / 120 次 | 1962605653 | 1% | 0/120 |
| 25学术部 1025377431 | ✅ | 只看不说 | — | — | — | 0 |

- 每行 5 个控件，改完 **60 秒内生效**（不需要重启）；
- 「在群里？」= 现在的白名单（去掉就是不在这个群）；
- 「怎么回」= 正常聊 / 只回@ / 只看不说（把 静音、学习模式、群模式 三个概念收成一个三选一）；
- 「发言量」= 三档 + 自定义（两个滑块合一）；
- 「只回谁」/「抽样」合并进同一行。

**删掉**：白名单页的静音按钮、安全页的三档卡、安全页的群发言频率卡、学习模式卡、按群规则卡 —— 共 5 个入口。

## 三、第二处合并：「说话」与「记忆」

| 现在 | 合并后 |
|---|---|
| 学说话（样本 + 立刻学 + 批量导入） | 说话 · Tab①学到的说法 |
| 她的看法（印象库） | 说话 · Tab②她的看法 |
| 人群档案 | 人（放"她认识的人"） |
| 记忆与情绪（心情条 + 曲线 + 气泡） | 记忆 · Tab①心情 |
| 记忆体检 | 记忆 · Tab②体检 |
| 记忆星海 | 记忆 · Tab③星海 |
| 记忆卡/欠事（散在概览） | 记忆 · Tab④卡片与欠事 |

理由：这些都是"她的内在"，用户找的时候想的是"她记得什么/她学什么"，不是"记忆体检在哪页"。

## 四、设置项：44 → 26

合并规则：**同一件事的"开关 + 参数"合成一行**（开关关掉时参数灰掉）。

| 合并前（44 项） | 合并后（26 项） |
|---|---|
| AI 暂停 + QQ 模式·关机 | ① 全局暂停（一个开关，顶上还有大按钮） |
| 自动看说说 + 看说说时间 | ② 看说说（开关 + 时间在一行） |
| 学说话 + 学说话时间 + 省钱也照学 | ③ 学说法（三合一） |
| B站每天学一个 + 每天几个 + 学完要不要说 | ④ B站学习（三合一） |
| 每个群的 22 个开关 | → 全部搬去「群规则」页，设置页不再出现 |
| 其余（记忆/日报/提醒/欠事/感情/工具档…） | 保留，分 5 组 |

设置页分组：**说话 / 记忆 / 自动任务 / 成本 / 安全**。

## 五、生效语义统一

| 类型 | 例子 | 显示 | 生效 |
|---|---|---|---|
| 热 | 群规则、抽样、静音、发言量 | 🟢 立即 | 60 秒内（桥接轮询） |
| 半热 | 省钱模式、工具档 | 🟡 60 秒 | 同上 + 重建提示词 |
| 冷 | 白名单删增、模型、端口 | 🔴 需重启 | 点「应用并重启」按钮 |

顶栏只有一个入口：「**待生效 0 项**」，点开是列表 + 一个「应用并重启」按钮。现在"待生效"偶发不归零的问题，在这个模型下会被消灭（因为热项不再产生待生效）。
