# 面板 P2 重规划（草案，先讨论再动手）

> 触发：用户反馈「功能重复」「改完看着都对但不生效」「页面太多找不到」。
> 原则：**先定 IA（信息架构）和生效模型，再改 UI**；不做推倒重写，只做「合并 + 搬家 + 语义修正」。

---

## 一、现在的三处重复（事实）

| 重复 | 位置 A | 位置 B | 实际底层 |
|---|---|---|---|
| 群开/关 | 白名单（加/删群） | 安全页「群模式」（正常聊/只听叫我/只看不说） | 白名单是 `allow.groups`；群模式改的是 `muted-keys.json` + `learn-mode.json` |
| 群发言量 | 安全页「三档卡」（活跃度） | 安全页「群发言频率」（滑块 + 预设档） | 同一份 `group-rate.json`，三档卡只是批量写 preset |
| 全局静默 | 功能开关「AI 暂停」 | 顶栏「QQ 模式·关机」 | 两个字段：`socialV2.paused` 与 `qq-mode.json` |

**结论**：不是 UI 重复，是**三个功能各自实现了一套"开关"，被摆在一起**。所以"看起来都改了，实际互相覆盖"。

---

## 二、目标 IA（三页，一级导航只有 3 个）

```
① 现在（只读）
   概览 · 自检 · 决策记录 · 她说的话 · 花费
② 她怎么说话（可改）
   群与人在不在（白名单 / 静音 / 只看不说）
   每个群说多少（3 档 + 自定义）
   什么时候不说（省钱模式 / 静音 / 敏感话题）
   她是谁（人格卡只读摘要 + 学习与印象）
③ 系统（可改）
   开关与工具档 · 重启与待生效 · 备份/归档 · 排障
```

一级导航从 6 组 20 页压到 **3 页 + 页内 Tab**。

---

## 三、语义修正（解决"改完不生效"）

**根因**：同一个"她在这个群说不说"，被 4 个文件表示（`allow.groups`、`muted-keys`、`learn-mode`、`group-rate`），每个都有独立默认值。

**方案：单一事实源 `group-policy.json`**

```json
{ "group:<gid>": {
    "present": true,          // 在不在这个群处理（等价白名单）
    "mode": "auto|mention|silent",   // 正常 / 只回@ / 只看不说
    "rate": {"minGapMin": 1, "perDay": 120, "level": "custom"},
    "sample": 1.0,            // 抽样%
    "replyOnly": ["1962605653"],
    "peakExempt": false
} }
```

- 老文件作为**迁移来源**，一次性写入新文件后彻底停用（不再读）；
- 面板只读写这一个文件，**不再有"多个地方都能改"**；
- "改完不生效"变成不可能：一个字段一个写入口。

---

## 四、生效模型（解决"点了没反应"）

| 类型 | 例子 | 生效方式 |
|---|---|---|
| 热 | 群模式、发言量、抽样、静音 | 桥接每 60 秒重读 `group-policy.json`（mtime 变化才读） |
| 半热 | 省钱模式、工具档 | 同上，但需要重建提示词（会自动发生） |
| 冷 | 白名单删增、端口/模型 | 明确标「需重启」+ 一键「应用并重启」按钮 |

面板上每个开关右侧统一显示：**「立即」/「60 秒内」/「需重启」**，点击后在顶栏出现倒计时。

---

## 五、执行顺序（三步，每步可验收）

| 步 | 内容 | 代价 | 风险 |
|---|---|---|---|
| P2-1 | 建 `group-policy.json` + 迁移脚本（读旧 4 个文件 → 写新文件）+ 桥接改为只读新文件 + 单测 | 1 天 | 中（迁移错会导致某群不响应） |
| P2-2 | 面板「她怎么说话」页：一个群一行，4 个字段（在不在/模式/发言量/抽样），改完 60 秒生效 | 1 天 | 低 |
| P2-3 | 删掉旧入口（三档卡、群频率卡、白名单静音按钮合并），导航压到 3 页 | 0.5 天 | 低 |
