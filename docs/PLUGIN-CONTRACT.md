# 插件接入契约（PLUGIN CONTRACT）

> 目的：让外部能力（记忆插件、检索、面板、工具）能接进这套系统，而**不用改 `bridge.js`**。
> 状态：V1 只定契约 + 一个只读示例；真正接第三方插件留 V2。

## 一、现在已有的钩子（接插件就用这些）

| 钩子 | 什么时候被调用 | 能做什么 |
|---|---|---|
| `promptBlock(cfg)` | 每次组装提示词 | 往提示词里加一段（返回字符串，空则跳过） |
| `wakeGate({key, reason})` | 每次唤醒前 | 返回 `false` / `{allow:false, reason}` 拦掉 |
| `routes[]` | HTTP 请求 | 提供 `/api/socialV2/xxx` 接口 |
| `onGroupMessage(ctx)` | 收到群消息 | 记录、打分、计数（不要在这里回消息） |
| `onPrivateMessage(ctx)` | 收到私聊 | 返回 `true` 表示已处理（不再走模型） |
| `afterSend(ctx)` | 消息发出后 | 记日志、写记忆、打标签 |
| `stateKey()` | 组装提示词前 | 返回一个字符串；文件变了缓存就失效 |

模块放在 `src/ext/<名字>.js`，默认导出一个对象，注册进 `src/ext/index.js` 的 `EXTENSIONS` 数组（顺序 = 提示词注入顺序）。

## 二、必须遵守的契约

1. **状态**：只能写在 `SURFCORE_STATE_DIR` 下，UTF-8 JSON；写文件用「临时文件 + rename」原子替换。
2. **不碰别人的文件**：不改 `config.json`、不写 `characters/`、不改别人的 state。
3. **失败要吞**：钩子里自己 `try/catch`，出错打一行日志，**绝不能抛到主流程**（历史上两次事故都是钩子抛错导致整条链断）。
4. **性能**：同步钩子 <50ms；`stateKey()` 只读一次 `stat`，不要读全文。
5. **幂等**：同一个事件重复到达，不产生重复记录。
6. **可关**：每个扩展在 config 里有开关，关掉后行为与没有它一致。

## 三、接一个外部插件（比如别人的记忆系统）的流程

1. **读它的数据模型**，列一张映射表：它的字段 → 我们的字段（`text` / `importance` / `clarity` / `conversationKey` / `createdAt`）。
2. **先只读**：写一个 adapter，只把它的数据**读**进来渲染成提示词块，**不写回去**。
3. **A/B**：开关切换，观察一周（记忆召回是否变准、有没有串台）。
4. **再考虑写回**：写回必须幂等 + 冲突规则（谁新谁赢 / 不同会话不合并）。
5. **回滚**：adapter 独立文件，删掉即可恢复。

## 四、什么时候不该接

- 它要求改我们的数据模型（比如必须用图数据库）；
- 它依赖自己的守护进程且失败会阻塞（记忆插件最常见）；
- 它的许可证是 AGPL 而我们计划闭源分发。
